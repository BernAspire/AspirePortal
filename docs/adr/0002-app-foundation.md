# ADR 0002: Next.js app foundation

Date: 29 Oct 2026 · Status: proposed (accepted on merge)

## Decision

- **Next.js 16** (App Router, Turbopack) with **Cache Components** on, as generated by `create-next-app`. Pages are static by default; anything that reads the user's session (cookies) renders inside a `<Suspense>` boundary.
- **`src/proxy.ts`** (Next 16's name for middleware) only refreshes the Supabase session cookie. It does not authorise. Access is decided by RLS and by server-side checks in each portal.
- **Supabase via `@supabase/ssr`**: `lib/supabase/server.ts` (server, `server-only`, user's session) and `lib/supabase/client.ts` (browser). Both use the anon key. No service-role client exists yet.
- **Environment** is validated with Zod at first use (`lib/env.ts`), so a build works without secrets and a missing value fails with a clear message.
- **Money** is carried as integer cents in `number`, guarded with `Number.isSafeInteger`; multiplication and rounding run in `bigint` so GST is exact. GST is per line, half-up, rate in basis points from centre settings.
- **Time** helpers evaluate business dates in `Asia/Singapore` with `@date-fns/tz`. Unit tests run with `TZ=UTC` so they cannot pass by accident on a Singapore machine.
- **Fonts** are self-hosted from the `geist` npm package, so builds and page loads make no calls to Google.
- **shadcn/ui** components (Radix base, new-york style) are committed under `src/components/ui`; `components.json` is in place so `pnpm dlx shadcn add <name>` works later.
- **Vercel** functions pinned to `sin1` via `vercel.json`.

## Why

These are the generator's defaults for the current Next.js release, plus the minimum needed to honour CLAUDE.md's rules on tenancy, money and time before any feature code is written.

## Consequences

- Session-reading UI must follow the Cache Components pattern (`node_modules/next/dist/docs/01-app/02-guides/authentication-with-cache-components.md`).
- The first four shadcn components were written from the upstream source because the build environment could not reach the shadcn registry. Future components should be added with the CLI.
